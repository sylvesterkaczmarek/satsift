# Publication benchmark protocol v0.4

## Scope

Benchmark v0.4 is the frozen public-evidence benchmark artifact for Satellite Maneuver Screening Workbench research. It contains actual Space-Track GP-history OMM records, public source citations, interval-censored maneuver evidence and verified-quiet controls across LEO, MEO, GEO and HEO.

It is not operator telemetry and does not convert public notices into exact burn truth.

## Label semantics

Each case declares one of the following statuses:

- `event-evidence`: one or more publicly documented maneuver intervals are scored for recall and detection delay.
- `verified-quiet`: authoritative evidence supports that commanded orbital maneuvering was unavailable, the spacecraft was passivated, or the operator states no further manoeuvres were required during the selected window. Predictions in these cases may contribute to the false-event denominator.
- `unknown`: the interval is useful for robustness analysis but is excluded from positive and negative performance denominators.

Absence of a listed maneuver is never treated as a negative label by default.

## Orbit-regime coverage

Version 0.4 includes explicit verified-quiet controls for:

- LEO: ERS-2 after passivation; GOCE after propulsion exhaustion in the test partition.
- MEO: GIOVE-B after retirement to graveyard orbit.
- GEO: Meteosat-7 after disposal; Meteosat-8 after disposal in the test partition.
- HEO: Cluster II Salsa after the January 2024 final targeting manoeuvres, during a period ESA subsequently described as requiring no further assistance before reentry.

Documented event cases cover LEO, MEO, GEO and HEO.

## Partitioning

All windows belonging to one NORAD object remain in a single satellite-level partition. Calibration and test objects do not overlap.

Benchmark v0.3 was used during physics-ML v0.1-v0.3 development. Its test outcomes therefore must not be represented as a final confirmatory holdout for a future method tuned after those outcomes were observed.

Benchmark v0.4 completes the benchmark artifact and coverage protocol. If a future detector is further tuned using v0.3/v0.4 information, a new benchmark version with previously unseen confirmatory objects must be frozen before the final evaluation.

## Metrics

Event matching uses the declared tolerance and one-to-one matching between predicted and labelled event intervals.

Report:

- event-level true positives and false negatives;
- recall;
- detection delay for matched events;
- false events only within `verified-quiet` windows;
- false events per verified-quiet object-month;
- scorable precision and F1 using verified negatives only;
- abstention rate;
- unscored predictions separately;
- satellite-cluster bootstrap 95% confidence intervals.

Do not silently classify unmatched predictions in `event-evidence` windows as false positives because public evidence is incomplete outside the documented intervals.

## Sampling stress

The deterministic stress suite removes observations without modifying retained epochs or orbital states. It includes quarter-drop, half-drop and contiguous middle-burst-loss variants. Report both event-presence stability and event-level metrics after thinning.

The v0.3 frozen stress report remains a development sensitivity result and is retained under `benchmark-results/`.

## Reproducibility

The benchmark is generated by `tools/build_public_evidence_benchmark.py` from the versioned manifest and same-site history endpoint. The committed dataset has a SHA-256 sidecar. The baseline runner, physics-ML runner, evaluator and sampling-stress scripts are committed in the repository.

Any paper must record:

- benchmark version and SHA-256;
- source commit SHA;
- detector version and settings;
- label/matching policy;
- calibration/test object allocation;
- any cases excluded and the reason;
- all primary metrics and confidence intervals.

## Qualification boundary

This benchmark supports reproducible public-evidence research. It does not establish operational SSA validation, maneuver confirmation, or operator-grade burn truth. Independent technical review remains a separate qualification activity.
