SatSift accessibility statement

The workbench is designed for keyboard operation, readable responsive layouts and non-visual access to core analysis data. This statement describes the current interface and the scope of its internal accessibility checks.

Open workbenchDocumentationBenchmark status

Implemented accessibility features

  • Keyboard-operable native controls, event selection and visible focus indicators.
  • Light and dark themes with text labels for analysis states.
  • Skip link to the main analysis result.
  • Programmatic labels, headings, landmarks and live status announcements.
  • Tabular alternative for chart data and textual summaries for candidate events.
  • Responsive layouts without intentional horizontal page scrolling.
  • Reduced-motion handling for users who request it.
  • 3D orbit context is supplemental; no decision depends on the graphic alone.

Internal review status

The repository retains the August 2026 internal review against a WCAG 2.2 AA-oriented checklist. The November 2026 console update has separate automated WCAG 2 A/AA and WCAG 2.1 AA checks, keyboard interaction tests, and desktop/mobile layout checks in both themes. These engineering checks do not establish complete conformance across browsers and assistive technologies.

This is an internal engineering review. It is not a formal Section 508 certification, third-party Accessibility Conformance Report or completed VPAT.

Known limitations

  • Interactive Plotly graphics may require additional screen-reader testing across specific browser and assistive-technology combinations.
  • The date-picker experience varies by browser and operating system.
  • Colour contrast and zoom were checked programmatically and manually for the supplied interface, but formal procurement review may require an external assessor.
  • Downloaded PNG charts are images; the JSON, CSV and chart-data table provide the machine-readable alternatives.

Reporting a problem

Report the affected page, browser, assistive technology and the action you were trying to complete through the contact route on Sylvester Kaczmarek's website.
